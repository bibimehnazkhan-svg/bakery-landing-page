# Golden Crumb Bakery — Landing Page

A responsive, single-page landing site for a bakery business.

## Features

- Sticky navigation with mobile hamburger menu
- Hero section with call-to-action buttons
- Features, menu, about, testimonials and contact sections
- Light, warm bakery-themed design with CSS custom properties
- Responsive layout for desktop, tablet and mobile
- Accessible: semantic HTML, visible focus states, `prefers-reduced-motion` support

## Tech

Plain HTML, CSS and vanilla JavaScript. No build step or dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html      # page markup
css/styles.css  # all styles
js/main.js      # mobile nav + footer year
```
